A problem that we are having is that players run into an end point where they have not got enough compatible letters to create new words.
This breaks one of the main design principles that we want to uphold here which is that players have a set boundary on their game. They know that there is a best answer for example there is a way of getting the puzzle correct.
If a player reaches one of these dead ends early and can't get past it, or can only get past it by using quite unusual words, then I think that would discourage them from playing again.
The solution to this is to choose a set of letters that allows for a lot of combinations of words to be made and has a correct answer. For example, showing the best score which might be 1x8 letter words 2x7 letter words 2x6 letter words. For example.
I'd like to come up with a way of programmatically creating start letters such that we know that the players can get all the way through to achieve some sort of best score.
